# Hi, I'm Lorenzo

Italian developer, born in 2003. I'm looking for my role in a world where AI advances every day. Meanwhile, I build.

## Code

The most notable thing I've worked on is [DoveVannoINostriSoldi](https://github.com/Italian-Builders-Org/DoveVannoINostriSoldi), an open-source civic project, made by a community, that makes Italian public data readable. I built the [government scorecard](https://www.dovevannoinostrisoldi.com/governi): since 1995 every government has a grade and nine charts compared with France, Germany and Spain. Then I stayed and worked on public debt, OpenCUP, parliamentary votes and data access for agents. It's the first time other people read and criticized my code, and that's what I was looking for.

Other projects I'm happy I wrote:

- [doclify-guardrail](https://github.com/Elgabor/doclify-guardrail), a CLI on npm that checks whether your docs still match your repository.
- [microgpt-c-v2](https://github.com/Elgabor/microgpt-c-v2), a GPT in pure C with no libraries, forked from Vishal Baraiya's microgpt-c. I added ten features to see what happens inside a model. After 2,000 steps it writes `for (int i = 0; coat = i++)`.
